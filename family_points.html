📖 가족포인트앱 사용법
✅ 할일
매일 정해진 할일을 체크하고 포인트를 모아요.
• 체크 — 할일 완료 시 버튼 클릭
• 마감 시간 — ⏰ 표시, 시간 전까지 체크해야 포인트 획득
• 유예 시간 — 마감 후 일정 시간 내 체크 시 감점 포인트로 인정
   예) 7시 전 5P → 7시~7시반 3P → 7시반 이후 마감
• 보너스 포인트 — 마감 전 완료 시 🌟 버튼으로 추가 포인트
• 이전 날짜 — ◀▶ 버튼으로 이동, 관리자만 수정 가능
• 확정 — 당일 체크 완료 후 확정 버튼으로 포인트 적립
🛍️ 쿠폰샵
• 모은 포인트로 쿠폰 구매
• 잔여 포인트 부족 시 구매 불가
• 구매한 쿠폰은 쿠폰함에 저장
• 관리자가 쿠폰 종류·가격 추가/수정 가능
🎫 쿠폰함
• 구매한 쿠폰 목록
• 사용 — 쿠폰 사용 처리 (사용됨으로 변경)
• 환불 — 사용 전 쿠폰 환불 시 포인트 반환
• 사용 취소 — 관리자 모드에서 사용됨 → 미사용으로 되돌리기
📋 내역
• 포인트 적립·사용 전체 기록
• 확정(+), 쿠폰구매(-), 환불(+) 순으로 표시
📅 월별
• 달력 형태로 날짜별 적립 포인트 확인
• 날짜 클릭 시 해당 날 할일 탭으로 이동
• 월 이동 ◀▶ 버튼으로 지난달 확인 가능
💰 포인트
• 총 포인트 — 지금까지 적립한 전체 포인트
• 이번 주 포인트 — 현재 보는 날짜 기준 해당 주 합산
• 날짜 이동해도 총 포인트는 항상 동일
⚙️ 설정
• 사용자 수 — 1명/2명 선택
• 이름 — 각 사용자 이름 설정
• 색상 — 각 사용자 테마 색상
• 보호자 이름 — 문의 안내 메시지에 표시
• 주 시작일 — 이번 주 포인트 기준 (일/월요일)
• 주간 목표 — 달성 시 오늘 팝업에 축하 메시지
• Google 연동 — GAS URL + 스프레드시트 ID 입력 시 클라우드 저장·동기화
🌅 오늘의 팝업
매일 할일 탭을 열 때 자동으로 떠요.

팝업이 뜨는 시점
• 앱을 처음 열 때
• 다른 탭에서 할일 탭으로 이동할 때
• 오늘 날짜에서 오늘 버튼 클릭 시 (항상)

팝업 내용
• 날짜·인사말·응원 메시지
• 총 포인트 (이안·로건)
• 이번 주 목표 달성 현황 (설정 시)
  — 미달성: 주황색 프로그레스 바 + 남은 포인트
  — 달성: 초록색 + 🎉 축하 메시지
• 오늘의 학습 (영단어·숙어·속담·사자성어·상식·두뇌자극)
  — 🔊 듣기: 영단어·숙어는 발음 재생
  — 🔄 버튼: 다른 내용으로 새로고침

오늘은 그만 보기
• 체크 후 닫으면 오늘 하루 팝업 안 뜸
• 체크 해제하면 다시 뜸
• 관리자 모드에서는 팝업 뜨지 않음
